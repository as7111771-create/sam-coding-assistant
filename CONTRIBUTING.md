# Contributing to Sam Coding Assistant

Thanks for your interest in contributing! 🚀

## Ways to Contribute

- Report bugs or suggest features by opening an issue
- Improve the UI/UX of the chat interface
- Add new features or enhance existing ones
- Improve documentation
- Fix typos or refactor code

## Getting Started

1. Fork the repository
2. Clone your fork: `git clone https://github.com/YOUR_USERNAME/sam-coding-assistant.git`
3. Install dependencies: `npm install`
4. Create a branch: `git checkout -b feature/your-feature-name`
5. Make your changes
6. Test locally: `npm run dev`
7. Push: `git push origin feature/your-feature-name`
8. Open a Pull Request

## Development Setup

- Node.js 18+
- npm or yarn
- Vite (included in devDependencies)

## Guidelines

- Follow the existing code style
- Use meaningful component names
- Add comments for complex logic
- Test your changes before submitting
- Keep the terminal aesthetic consistent

## Commit Messages

Use clear, descriptive commit messages:
- `feat:` for new features
- `fix:` for bug fixes
- `docs:` for documentation changes
- `refactor:` for code refactoring
- `style:` for styling changes

## Questions?

Feel free to open an issue with the `question` label!
